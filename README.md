# Danilo Machado — Portfólio Pessoal

Site pessoal desenvolvido para reunir meus projetos, formação e contato em um só lugar, enquanto busco minha primeira oportunidade de estágio em desenvolvimento.

🔗 **Site no ar:** [danmachado3105.github.io](https://danmachado3105.github.io)

## Sobre o projeto

Construído com HTML, CSS e JavaScript puro — sem frameworks — como exercício prático enquanto aprendo front-end. O objetivo foi ter controle total sobre cada linha de código e entender de verdade o que estava sendo escrito, em vez de depender de um template pronto.

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, variáveis CSS)
- JavaScript (vanilla)
- Hospedagem via GitHub Pages

## Rodando localmente

Não há dependências ou build — basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.
